# lora-kue-tradisional

Fine-tuning **Stable Diffusion XL Base 1.0** dengan **LoRA** untuk menghasilkan gambar kue tradisional Indonesia (klepon, serabi, dadar gulung, dll.) yang bentuk dan teksturnya sesuai aslinya. Proyek kelompok mata kuliah Generative AI, Proyek 2 Fine-Tuning Local LLM (CAK4KBB3 2026-1).

| | |
|---|---|
| **Sistem** | Local Indonesian Traditional Cake Image Generator (Gradio UI) |
| **Library** | Hugging Face Diffusers, PEFT (LoRA), Accelerate, Gradio |
| **Backbone** | Stable Diffusion XL Base 1.0 |
| **Target** | Menghasilkan gambar kue tradisional Indonesia secara realistis dan akurat |
